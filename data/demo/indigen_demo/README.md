# IndiGen Demo — Synthetic Data, Not Official IndiGen Evidence

`indigen_demo_v1.json.gz` is **synthetic demonstration data** generated by `scripts/build_indigen_demo.py` (seed 20261009).

- Allele counts, allele numbers and frequencies are produced by a seeded pseudo-random process. They were **not** measured from Indian
  genomes, **not** derived from gnomAD, and **not** obtained from CSIR-IGIB or the IndiGen programme.
- Only the variant identifiers (GRCh38 `chrom:pos:ref:alt`) and ClinVar VariationIDs are real, so demo rows line up with the real
  ClinVar / gnomAD rows in the genomic panel.
- The file is read only by `src/population/indigen_demo.py` for display (opt-in demo mode). It never enters disease ranking, the
  population lookup, patient-level conclusions, or the real-source caches.

Real IndiGen data (with authorised access from CSIR-IGIB) goes to `data/raw/indigen/` and is ingested by
`src/population/indigen_adapter.py`; when present, it replaces the demo automatically.
